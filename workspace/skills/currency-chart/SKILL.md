# График курса валют (ЦБ РФ)

Строй графики **официальных курсов ЦБ РФ** к рублю: доллар, евро, юань и любые другие
валюты из справочника ЦБ. Данные бесплатные, без API-ключей. Используй только
`web_fetch` (получение данных) и `message` (отправка картинки) — `exec` обычным
пользователям недоступен, он здесь не нужен.

Если пользователя интересует просто текущий курс без графика — выполни только шаги 1–2
и ответь текстом, картинку не отправляй.

## Шаги

1. **Определи параметры запроса**: валюту (ISO-код или название: «доллар» → USD,
   «евро» → EUR, «юань» → CNY и т.д.) и период. Период по умолчанию — 30 дней,
   допустимый диапазон 7–180 дней. Если просят больше 180 дней — агрегируй данные
   по неделям и предупреди об этом.

2. **Возьми текущий курс и ID валюты** одним запросом:
   `web_fetch https://www.cbr-xml-daily.ru/daily_json.js`
   Это JSON: `Valute` → найди валюту по `CharCode` (USD, EUR, CNY…) и возьми поля
   `ID` (например `R01235`), `Nominal`, `Value`, `Previous`, `Date`. Если валюты нет
   в справочнике — так и скажи, перечислив несколько популярных (USD, EUR, CNY, GBP,
   JPY, CHF, KZT, TRY).

3. **Получи историю за период** одним запросом к официальному API ЦБ:
   `web_fetch https://www.cbr.ru/scripts/XML_dynamic.asp?date_req1=<ДД/ММ/ГГГГ>&date_req2=<ДД/ММ/ГГГГ>&VAL_NM_RQ=<ID>`
   где даты — «сегодня минус период» и сегодня в формате ДД/ММ/ГГГГ, а `<ID>` взят из шага 2.
   В ответе XML: `<Record Date="ДД.ММ.ГГГГ" ...><Nominal>1</Nominal><Value>81,5135</Value>...`
   на каждую рабочую дату. Значение `Value` — с запятой в качестве десятичного
   разделителя. Курс за 1 единицу валюты = `Value / Nominal` (у JPY и KZT номинал 100).

4. **Построй график**: собери Chart.js-конфиг (линейный график: по X — даты, по Y —
   курс за 1 единицу валюты) и закодируй его в URL QuickChart:
   `https://quickchart.io/chart?w=900&h=500&devicePixelRatio=2&bkg=white&c=<URL-encoded Chart.js конфиг>`
   (w/h — крупный размер картинки, devicePixelRatio=2 — чёткость при увеличении,
   bkg=white — чтобы график не сливался с тёмной темой Telegram).
   Пример конфига (перед вставкой в URL — URL-encode, например через encodeURIComponent):

   ```json
   {
     "type": "line",
     "data": {
       "labels": ["01.08", "02.08", "…"],
       "datasets": [{"label": "USD/RUB", "data": [81.2, 81.5], "borderColor": "#2b6cb0", "fill": false}]
     },
     "options": {
       "title": {"display": true, "text": "Курс USD к рублю (ЦБ РФ), 30 дней", "fontSize": 20},
       "legend": {"labels": {"fontSize": 14}},
       "scales": {
         "yAxes": [{
           "ticks": {
             "beginAtZero": false,
             "fontSize": 13,
             "suggestedMin": 80.9,
             "suggestedMax": 83.7
           }
         }],
         "xAxes": [{"ticks": {"fontSize": 12, "maxTicksLimit": 10}}]
       }
     }
   }
   ```

   Важно: ось Y не должна начинаться от нуля — иначе при курсе ~80–85 ₽ график
   выглядит как почти горизонтальная линия. Всегда задавай `suggestedMin` и
   `suggestedMax` по фактическим минимуму и максимуму ряда с небольшим отступом
   (±2–3% диапазона; в примере данные 81.2…83.45 → suggestedMin 80.9,
   suggestedMax 83.7).
   Если URL получается длиннее ~6000 символов (много точек) — переходи на недельную
   агрегацию или сократи период.

   Никогда не переиспользуй ссылку на график из своих прошлых ответов: даже если
   данные не изменились, каждый раз собирай конфиг и URL заново строго по шагам
   этого скилла. Правило про suggestedMin/suggestedMax и размер картинки —
   обязательная часть каждого нового графика.

5. **Отправь картинку**: инструментом `message`, action `send`, в текущий чат,
   параметр `media` = URL из шага 4. Затем отправь вторым сообщением текстовую сводку.
   Если `message send` с media не сработал — просто дай ссылку на QuickChart в обычном
   ответе: Telegram покажет картинку как превью ссылки.

## Формат ответа

Картинка (график) + короткий текст под ним, например:

> 📈 Курс USD к рублю (ЦБ РФ), 30 дней: 81.20 → 83.45 ₽ (+2.8%).
> Минимум 80.90, максимум 83.45. Текущий курс: 83.45 ₽ (на 10.09.2026).

Курсы округляй до копеек, проценты — до одного знака. Всегда указывай, что это
официальный курс ЦБ РФ (он обновляется раз в рабочий день и действует со следующего).

## Ошибки и ограничения

- **web_fetch вернул не XML/не JSON (обрезал или переоформил)**: для периодов до
  14 дней собери серию по дням через архив
  `web_fetch https://www.cbr-xml-daily.ru/archive/<ГГГГ>/<ММ>/<ДД>/daily_json.js`
  (по одному запросу на дату, бери `Valute.<CHARCODE>.Value`).
- **QuickChart недоступен или вернул ошибку**: ответь текстом — таблица значений по
  датам и юникод-спарклайн из блоков ▁▂▃▅▆▇ (нормируй ряд на min/max).
- **Ни один источник не отвечает**: честно скажи об этом и предложи повторить позже.
- Только курсы к рублю и периоды 7–180 дней. Кросс-курсы (например EUR/USD) и
  биржевые котировки в реальном времени этот скилл не даёт.
- Никаких секретов в этом скилле нет и не нужно: источники публичные.
